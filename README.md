Student Management System (C++)

This program is a console-based Student Management System designed to record, manage, and update student information using a structured, menu-driven interface. It demonstrates core programming concepts such as input validation, file handling, and modular function design in C++.

Key Features
➤ Add Student Records

Stores roll number, name, department, and semester

Validates input and prevents duplicate entries

➤ View All Students

Displays all saved records in a clean, structured format

➤ Search Students

Search by roll number or name

Shows complete details of the matched student

➤ Update Student Information

Modify name, department, and semester of any existing record

➤ Delete Student Records

Safely removes selected entries

Ensures no invalid or empty data is processed

➤ File Handling (Persistent Storage)

Saves and retrieves student data using a text file

Keeps records preserved across multiple program runs

➤ User-Friendly Menu System

Clear options, smooth navigation, and repeated menu display
